# Week 1 – Python Basics & Control Structures

## Assignments

1. **Temperature Converter** – Celsius ↔ Fahrenheit using functions.
2. **Student Grade Calculator** – accepts subject marks, calculates average, and assigns a grade.
3. **Even/Odd & Prime Checker** – checks whether an integer is even/odd and prime/non-prime.

## Mini Project

**Simple ATM Simulator**
- PIN-based login
- Check balance
- Deposit money
- Withdraw money with insufficient-balance validation
- Menu-driven loop
- Functions for each major operation

## Run

Use Python 3:

```bash
python 01_temperature_converter.py
python 02_student_grade_calculator.py
python 03_even_odd_prime_checker.py
python 04_atm_simulator.py
```
