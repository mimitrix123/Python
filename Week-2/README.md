# Week 2 – Data Structures & File Handling

Completed from the provided Week 2 material.

## Assignments

1. **Contact Book** – dictionary-based Add, Search, Update, Delete and Show All operations.
2. **Word Counter** – reads a text file and counts words, lines, and characters with exception handling.
3. **JSON File Reader** – loads JSON and prints formatted output with error handling.

## Practice Set

- List CRUD operations
- Dictionary word-frequency counter
- Nested-loop star pattern
- Largest and smallest number in a list
- Sorting with `sort()` / `lambda` concepts

## Mini Project – Student Management System

- Stores student roll number, name, and marks in `students.csv`
- Add, Search, Delete and Show All operations
- Changes are saved permanently to the CSV file
- Handles invalid input and file errors

## Run

Use Python 3:

```bash
python 01_contact_book.py
python 02_word_counter.py
python 03_json_reader.py
python 04_practice_set.py
python 05_student_management_system.py
```

The included `students.csv` contains sample records and will be updated by the mini project.
